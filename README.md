## Files
- `index.html` — page content and SEO metadata
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, scroll progress and reveal animations
- `assets/profile.jpg` — uploaded profile photograph
- `sitemap.xml` — search-engine sitemap
- `robots.txt` — crawler directives

## Run locally
Open `index.html` in a browser.

For a local development server, from this folder run:
`python -m http.server 8000`

Then visit:
`http://localhost:8000`

## Publish
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel or any normal web server.

## Notes
The portfolio content is based on the supplied 2026 CV. Phone number and residential addresses were intentionally not displayed on the public-facing page; email, LinkedIn and ResearchGate are provided instead.
